# Процедурные 3D-модели машин для Blender

Шесть машин по присланным концепт-рендерам. Каждая модель целиком строится
Python-скриптом через `bpy` и сохраняется в `.blend`:

| Файл | Машина | Что смоделировано |
|---|---|---|
| `output/VAZ2106_Restomod.blend` | ВАЗ-2106 widebody restomod | кузов с расширителями, 4 круглые LED-фары, решётка, воздухозаборники, сплиттер, антикрыло, LED-полоса фонарей, диффузор, люк, «раздвоенные» 10-спицевые диски |
| `output/ZAZ968_Coupe.blend` | ЗАЗ-968 Coupe | фастбэк, круглые фары с LED-кольцами, хромовый молдинг по борту, боковые жалюзи, круглые фонари, номера «968A», диски-«турбины» |
| `output/LADA2107_NewGen.blend` | LADA 2107 «Новое поколение» | решётка с сеткой и надписью LADA, L-образные LED-фары с линзами, угловые воздухозаборники, тонкие фонари, трапециевидные выхлопы, 5-лопастные аэродиски |
| `output/Nova63_Restomod.blend` | Chevy II Nova 1963 restomod | хардтоп без стойки B, карбоновый капот, чёрные бамперы, круглые фары с halo, глубокие диски с полированной полкой |
| `output/VAZ2108_2025.blend` | ВАЗ-2108 «2025» | клиновидный хэтчбек, узкие LED-полосы в чёрной панели, сквозной фонарь с надписью LADA, спойлер, 5-спицевые диски |
| `output/ZIL111_Restomod.blend` | ЗИЛ-111 restomod (по рендеру STRUKOVART28) | «нависающие» передние крылья с голубыми LED-дугами, хромовые молдинги, кили, серые бамперы, колпаки-диски с белым кольцом |

Общее для всех моделей:
- настоящие оконные проёмы (видно салон: сиденья, торпедо с экранами, руль, тоннель);
- стёкла с чёрной рамкой, дворники, зеркала, ручки, зазоры дверей, капота и багажника;
- колёса: шина с протектором, обод с полкой, спицы или диск, гайки, колпачок, тормозной диск и суппорт;
- материалы Principled BSDF: краска с лаком, хром, карбон, резина, светящиеся LED;
- студия (циклорама и свет) и 6 камер: `cam_front34`, `cam_side`, `cam_rear34`, `cam_front`, `cam_rear`, `cam_top`.

Превью лежат в `output/renders/` (вид спереди 3/4, сбоку, сзади 3/4), общий коллаж — `output/overview.png`.

## Как открыть

Откройте `.blend` в Blender 4.2+ (собирались в 5.2). Вся машина висит на одном
пустом объекте с её именем: двигайте или вращайте его. Салон лежит во вложенной
коллекции `Interior`, студия — в `Studio` (её можно скрыть). Симметричные детали
сделаны через модификатор Mirror и остаются редактируемыми.

## Как пересобрать или изменить

```bash
pip install bpy            # или используйте Python, встроенный в Blender
python build.py            # все машины, рендер 1600x900
python build.py vaz2106 zil111 --samples 64 --res 1280x720
python build.py --no-render          # только .blend
blender -b -P build.py -- lada2107   # то же самое через Blender
```

Форма каждой машины задаётся таблицей сечений в `cars/<машина>.py`:
- `rows` для `B.Body` — ширины и высоты кузова по длине (`x`, м; перед машины смотрит в +X);
- `B.Greenhouse` — кабина: лобовое стекло, крыша, заднее стекло;
- дальше идут детали: фары, решётки, бамперы, колёса (`WheelSpec`).

Меняете числа, запускаете `build.py`, получаете новый `.blend`.

Библиотека `carlib/`:
- `body.py` — лофт кузова и кабины, вырезы арок и салона, проекция деталей на поверхность;
- `wheels.py` — шины, ободья, спицы, тормоза;
- `details.py` — фары, стёкла, зеркала, салон, антикрылья, выхлопы;
- `parts.py` — базовые генераторы (вращение, протяжка, призмы);
- `materials.py`, `studio.py`, `assemble.py`.

## Ограничения

Это процедурные модели, построенные «на глаз» по фотографиям. Это не фотограмметрия
и не скан. Пропорции и силуэты подобраны по рендерам, точные размеры оригиналов
неизвестны. Мелкие эмблемы, надписи на шинах и фактура салона упрощены.

## Игра: Drift Restomod

`game/drift_restomod.html` — браузерная игра про дрифт на этих шести машинах. Это один файл
(~7 МБ): three.js и модели встроены внутрь, интернет не нужен. Открывается в Chrome, Safari,
Firefox или Edge, на компьютере и на телефоне.

- **Карты.** «Город»: 7×7 кварталов, дома, тротуары с бордюрами, разметка, «зебры», фонари,
  светофоры, деревья, два парка (трава, сцепление ниже), две парковки с машинами и площадь для
  дрифта в центре. «Полигон»: кольцевая трасса с таймером круга.
- **Физика** (`game/src/physics.js`): четыре колеса со своим вращением; шины по формуле Пасейки
  с кругом трения, чувствительностью к нагрузке и длиной релаксации; продольный и поперечный перенос
  веса; мотор с кривой момента, сцепление, коробка (автомат или ручная), самоблок, полный привод
  у 2108; ABS, ручник на заднюю ось, аэродинамика, сопротивление качению. Шаг расчёта 600 Гц.
- **Помощь** (переключается в меню): ABS, антибукс, «помощь рулю» (колёса держат пиковый угол
  увода и выравниваются по ходу, если отпустить руль) и «анти-разворот». Без них машина ведёт
  себя как настоящая заднеприводная: газ в пол в повороте — разворот.
- **Управление:** W/↑ газ, S/↓ тормоз (стоя на месте — задний ход), A D/← → руль, пробел ручник,
  Q/E передачи, C камера, R поставить на колёса, M звук, Esc меню. Работает геймпад, на телефоне
  экранные кнопки.
- **Очки:** угол заноса × скорость, множитель до x5 за долгий занос, удар сбрасывает комбо.
  Рекорды сохраняются в браузере.
- **Пересборка:** `python export_game.py` (из `.blend` в `game/assets/`), затем
  `python game/build_html.py`. Исходники игры: `game/src/` (`physics.js`, `city.js`, `track.js`,
  `game.js`, `index.html`).
