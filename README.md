# Под фундаментом

2D пиксельный хоррор-адвенчур по сценарию «Под фундаментом»: point-and-click с видом сбоку, без боёв, 6 актов и две концовки («Побег» и «Покой»).

## Скачать и играть (Windows)

1. Скачать [`release/PodFundamentom_Windows.zip`](release/PodFundamentom_Windows.zip).
2. Распаковать и запустить `PodFundamentom.exe` (все `.dll` должны лежать рядом).

## Управление

| Клавиша | Действие |
|---|---|
| ЛКМ | идти / осмотреть предмет |
| ПКМ | отмена |
| A / D | шаг влево / вправо |
| F | фонарь, колесо мыши — тусклый режим |
| R | сменить батарейку |
| Q (держать) | «Слушать» — диктофон Лёхи |
| Пробел (держать) | «Замри»: дышать, когда полоска в зелёном окне |
| Tab / M | дневник / карта |
| C | метка мелом (Shift+C — крест) |
| E / Enter | пропустить реплику |
| Esc / F11 | пауза / полный экран |

Сохранение происходит на скамейках и у свечей.

## Настройки

В главном меню и в паузе (Esc): общая громкость, музыка, звуки и голоса, яркость с калибровкой, зерно плёнки, искажения при испуге, тряска экрана, подсказки, полный экран. Настройки сохраняются между запусками.

## Музыка и графика

- 8 музыкальных треков синтезируются игрой в фоновом потоке при запуске: титры, отдельные темы для актов, погоня, обе концовки.
- Свет: объёмный луч фонаря с пылью в воздухе, свечение источников, пиксельный дизеринг, зерно плёнки, хроматическая аберрация при испугах, виньетка от паники Лёхи.
- Туман у пола, капли и пыль, подтёки и трещины на стенах, передний план с трубами и кабелями, переходы пиксельным растворением.

## Структура

- `game/` — исходники на LÖVE 11.5 (Lua). Графика и звук генерируются кодом, отдельных ассетов нет.
  - `src/scenes/act1.lua` … `act6.lua`, `endings.lua` — сцены, триггеры и реплики по актам.
  - `src/data/docs.lua` — полные тексты записок.
  - `src/world.lua`, `src/ui.lua`, `src/dialog.lua`, `src/audio.lua` — ядро, интерфейс, диалоги, синтез звука.
  - `src/musicthread.lua` — генератор музыки, `src/settings.lua` — настройки, `src/title.lua` — титульный экран.
- `build/build_windows.sh` — сборка Windows-версии (LÖVE + игра в одном `.exe`).
- `release/` — готовые сборки: `PodFundamentom_Windows.zip` и `PodFundamentom.love` (для Linux/macOS: `love PodFundamentom.love`).

## Сборка

```bash
./build/build_windows.sh
```

Автопрохождение для проверки (нужен установленный `love`):

```bash
love game --test B
```

## Лицензии

Движок LÖVE — zlib. Шрифт — Handjet (SIL OFL 1.1).
