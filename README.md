# Vsacoe — ограды для рабочего стола Windows

Vsacoe — бесплатный аналог **Stardock Fences**. Программа группирует значки рабочего стола в полупрозрачные области («ограды»), которые можно двигать, сворачивать, раскрашивать и автоматически наполнять по правилам.

Работает в Windows 10 и 11. Написана на C# / WPF (.NET 8).

## Возможности

| Возможность | Как пользоваться |
|---|---|
| **Ограды** | Полупрозрачные области на рабочем столе. Они не попадают в Alt+Tab и на панель задач, остаются под окнами и не пропадают после Win+D. |
| **Перетаскивание** | Перетащите файлы, папки или ярлыки с рабочего стола или из Проводника в ограду. Внутри ограды значки можно переставлять и переносить между оградами. Если вытащить значок обратно на рабочий стол, он вернётся туда. |
| **Сворачивание** | Двойной щелчок по заголовку сворачивает ограду до одной строки. Свёрнутая ограда раскрывается при наведении мыши или при перетаскивании на неё файла. |
| **Быстрое скрытие** | Двойной щелчок по пустому месту рабочего стола скрывает или показывает все ограды и значки. |
| **Портал папки** | Ограда показывает содержимое любой папки на диске и обновляется сама. Двойной щелчок по подпапке открывает её, Backspace или кнопка «‹» возвращают назад. Файлы, брошенные в портал, перемещаются в эту папку (с Ctrl — копируются). |
| **Правила сортировки** | Новые файлы на рабочем столе сами раскладываются по оградам. Правило задаётся по расширению (`jpg; png`), маске имени (`Отчёт*`) или категории (Ярлык, Папка, Документ, Изображение, Видео, Аудио, Архив, Программа). |
| **Быстрая настройка** | Пункт в меню трея создаёт ограды «Программы», «Папки», «Документы» и «Медиа» с правилами и сразу раскладывает по ним рабочий стол. |
| **Скрытие стандартных значков** | Файлы рабочего стола показываются только в оградах. Неразложенные элементы и Корзина попадают в ограду «для всего остального». |
| **Внешний вид** | Цвет (готовые варианты или любой свой), непрозрачность, размер значков, сортировка по имени, типу, дате или размеру. |
| **Сетка и прилипание** | Ограды выравниваются по сетке и прилипают к краям экрана и друг к другу. Их можно закрепить, чтобы случайно не сдвинуть. |
| **Снимки макета** | Можно сохранить и восстановить расположение всех оград, например для разных мониторов или разрешений. |
| **Автозапуск** | Включается в настройках («Запускать вместе с Windows»). |

### Клавиши в ограде

`Enter` — открыть, `F2` — переименовать (если ничего не выделено — переименовать ограду), `Delete` — удалить в Корзину, `Ctrl+A` — выделить всё, `Ctrl`/`Shift`+щелчок — выделить несколько, `F5` — обновить значки, `Backspace` — назад в портале.

Правый щелчок по значку открывает меню файла: открыть, показать в папке, переименовать, удалить, убрать из ограды, переместить в другую ограду, свойства.
Правый щелчок по пустому месту или заголовку открывает меню ограды.

## Установка

1. Откройте вкладку **Actions** репозитория, выберите последнюю успешную сборку **Build** и скачайте артефакт `Vsacoe-win-x64`.
2. Распакуйте `Vsacoe.exe` в любую папку и запустите. Установка не нужна, .NET ставить отдельно тоже не нужно: всё уже внутри exe.
3. В области уведомлений появится значок. Правый щелчок по нему открывает главное меню.

Настройки, журнал и снимки хранятся в `%APPDATA%\Vsacoe`.

## Сборка из исходников

```powershell
dotnet test tests/Vsacoe.Core.Tests
dotnet publish src/Vsacoe/Vsacoe.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -o publish
```

Нужен .NET 8 SDK. Проект собирается и на Linux/macOS (`EnableWindowsTargeting`), но запускается только в Windows.

## Как это устроено

```
src/Vsacoe.Core/      Логика без привязки к Windows (покрыта тестами)
  Models.cs           Ограды, правила, настройки, снимки
  RuleEngine.cs       Сопоставление файлов с правилами
  FenceItemOps.cs     Перемещение, переименование и удаление элементов
  SnapMath.cs         Сетка и прилипание к краям
  ConfigStore.cs      JSON-хранилище с атомарной записью
src/Vsacoe/           Приложение WPF
  Interop/            Win32: окна рабочего стола, глобальный перехват двойного щелчка
  Shell/              Значки и миниатюры (IShellItemImageFactory), операции с файлами
  Services/           FenceManager, наблюдение за рабочим столом, трей, автозапуск
  Views/              Окно ограды, настройки, диалоги
tests/Vsacoe.Core.Tests/
```

Технические детали:

- **Привязка к рабочему столу.** Владельцем окна ограды становится окно рабочего стола (`Progman` или `WorkerW` с `SHELLDLL_DefView`). Обработчик `WM_WINDOWPOSCHANGING` держит ограду сразу над обоями. Если Проводник перезапустится (сообщение `TaskbarCreated`), ограды снова привязываются к рабочему столу.
- **Обычные ограды хранят ссылки на файлы, а сами файлы не двигаются.** При перетаскивании из Проводника программа отвечает эффектом Link/Copy и никогда Move, поэтому Проводник не удаляет исходники.
- **Скрытие значков** — это `ShowWindow(SysListView32, SW_HIDE)`. Значки возвращаются при выходе из программы, а после аварийного завершения — при следующем запуске. Если вы сами скрыли значки в Проводнике («Вид → Отображать значки рабочего стола»), программа это уважает.
