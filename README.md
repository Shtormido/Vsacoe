# 🏙️ Градострой

Красивый 2D-градостроитель в изометрии для браузера: от первой улицы до небоскрёбов. Работает на компьютере и телефоне, без установки и без сервера.

## Запуск

Откройте `index.html` в браузере (Chrome, Firefox, Edge, Safari) двойным щелчком.
Для телефона: опубликуйте папку через GitHub Pages (Settings → Pages → ветка `Grado_stroi`) и откройте ссылку.

## Что есть в игре

- **Дороги и мосты.** Прокладка перетаскиванием, над водой автоматически строится мост.
- **Зоны R / C / I.** Жилые, коммерческие и промышленные районы растут сами в зависимости от спроса (индикатор RCI). Дома растут до 4 уровней: домик → таунхаус → многоэтажка → небоскрёб.
- **Коммуналка через дорожную сеть:** электричество (ветряк, ТЭС, солнечная, АЭС), вода (башня, насосная), канализация, вывоз мусора (полигон, переработка). Без них жители уезжают.
- **Службы:** полиция, пожарные, поликлиника/больница, школа/библиотека/университет, парки, площади, стадион.
- **Достопримечательности:** мэрия, монумент, колесо обозрения, телебашня.
- **Экономика:** налоги по зонам, содержание построек, ежедневный бюджет, городской праздник с фейерверками.
- **Уровни мэра и опыт:** новые здания открываются по мере роста. 29 заданий с наградами.
- **Жители:** монетки 💰 и сообщения 💬 над домами, счастье, стоимость земли.
- **Происшествия и бедствия:** пожары (тушатся пожарными или вручную), преступления, торнадо, метеорит. Дождь тушит пожары.
- **12 слоёв данных:** коммуналка, стоимость земли, загрязнение, преступность, охват служб.
- **Красота:** процедурная графика высокого разрешения, тени, смена дня и ночи с огнями окон и фонарей, дым из труб, облака, дождь, машины и грузовики, вращающиеся ветряки и колесо обозрения, утки в пруду.
- **Регион из нескольких городов (до 4).** С 3-го уровня мэра можно основать новый город и переключаться между ними. Пока вы в одном городе, остальные живут сами: добывают ресурсы и копят деньги.
- **Специализации городов:** ⛰️ горный край (камень), ⚫ угольный бассейн (уголь), 🌲 лесной край (древесина), 🏖️ курорт (пляжи и туристы), а также река и озёра.
- **Ресурсы и торговля:** каменоломня, угольная шахта и лесопилка добывают ресурсы у залежей. Камень и древесина нужны для роста зданий, уголь — топливо для ТЭС. Между городами настраиваются торговые маршруты (получатель платит отправителю), излишки можно продать на внешний рынок, а нехватку — докупить.
- **Туризм:** пляжные клубы и отели, привлекательность от пляжей, парков и достопримечательностей. Чем больше население региона, тем больше туристов.
- **Режимы:** «Карьера» и «Песочница» (бесконечные деньги, всё открыто).
- Мини-карта, статистика с графиками, автосохранение, перемещение зданий.

## Управление

| Действие | Мышь / клавиатура | Телефон |
|---|---|---|
| Строить | ЛКМ (перетаскивание для дорог и зон) | палец |
| Двигать карту | ПКМ, колесо-кнопка, пробел+ЛКМ, WASD/стрелки | два пальца (или палец в режиме осмотра) |
| Масштаб | колесо мыши, `+` / `-` | щипок |
| Отмена инструмента | `Esc` или ПКМ | ✕ на подсказке |
| Пауза / скорость | `P`, `1`–`3` | кнопки вверху |
| Дорога / снос | `R` / `B` | — |

## Структура

```
index.html        — разметка интерфейса
css/style.css     — оформление
js/util.js        — утилиты, цвета, шум
js/config.js      — здания, инструменты, задания
js/region.js      — регион, города, склады, торговля
js/mapgen.js      — генерация ландшафта
js/sprites.js     — процедурная отрисовка всех спрайтов
js/game.js        — симуляция города, экономика, бедствия, сохранения
js/render.js      — изометрический рендер, свет, частицы, машины
js/ui.js          — интерфейс, окна, уведомления
js/audio.js       — синтезированные звуки
js/main.js        — ввод и главный цикл
```
