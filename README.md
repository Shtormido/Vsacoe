# Zapret Ultimate Edition

Портативный менеджер для [zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube) в стиле Windows 11. Он работает сразу с несколькими версиями запрета, держит свои стратегии и списки отдельно от версий, хранит профили настроек, сам подбирает лучшую стратегию и ставит её как сервис.

## Возможности

| Вкладка | Что умеет |
|---|---|
| **Главная** | Индикатор состояния: серый — выключен, зелёный — работает, фиолетовый — сервис, оранжевый — проверка или запуск. Под ним строка с деталями: батник, версия, профиль, фейки, Game Filter, IPSet, время работы, PID. Здесь же быстрый запуск, кнопка «Подобрать оптимальный» и управление сервисом. |
| **Стратегии** | Батники выбранной версии и свои стратегии. Для каждого показан разбор итоговой команды winws по секциям `--new`, есть копирование в свои, редактор и последняя оценка проверки. |
| **Настройки обхода** | Game Filter (режим и порты), IPSet (loaded / none / any), фейки по слотам (QUIC, TLS, HTTP, Discord/STUN, Game UDP/TCP, seqovl), подмена SNI, повторы, общие списки, TCP timestamps, доп. аргументы. Настройки задаются слоями: **база → профиль → версия → батник**. |
| **Профили** | Сохранённые наборы настроек, при желании с привязанной стратегией. Переключать можно в программе и из трея. |
| **Списки** | `list-general-user`, `list-exclude-user`, `ipset-exclude-user`, `targets.txt` и другие. Комментарии `# Название` показываются как сворачиваемые группы: строки можно добавлять, править, удалять и перетаскивать между группами. Есть текстовый режим. Формат файлов не меняется. |
| **Проверка** | Быстрая: все или выбранные стратегии. Полная: стратегии × фейки — сначала все батники с фейком №1, потом все с №2 и т.д. Типы проверки: стандартная (HTTP / TLS1.2 / TLS1.3 + ping по `targets.txt` с выбором групп) или DPI 16–20 КБ. Результаты выводятся таблицей и тепловой матрицей, лучший вариант применяется одной кнопкой, есть история. |
| **Сервис** | Установка, смена, остановка и удаление службы `zapret`, диагностика из `service.bat` с исправлениями в один клик, журнал winws. |
| **Версии** | Автопоиск версий, их возможности (формат Game Filter, IPSet, ACTIVE-фейки), проверка обновлений на GitHub, обновление `ipset-all.txt`. |
| **Оформление** | 12 готовых тем. Можно настроить всё: 21 цвет с прозрачностью, шрифты интерфейса, заголовков и моноширинный (включая системные), размер шрифта, скругления, плотность, ширину меню, материал окна (Mica / Mica Alt / Акрил), скорость анимаций, фоновое изображение, вид индикатора. Свои темы сохраняются, экспортируются и импортируются. |

## Как это устроено

- **Файлы версий не меняются.** Программа сама разбирает батник: склеивает переносы `^`, раскрывает `%BIN%`, `%LISTS%`, `%GameFilter*%`, `%~dp0`, `set` и `^!`, а затем запускает `winws.exe` напрямую с итоговыми аргументами. Режимы IPSet работают через служебные файлы, замена фейков и общих списков — через подмену путей.
- **Совместимость со старыми версиями.** Поддерживается и старый `%GameFilter%`, и новый `%GameFilterTCP%/%GameFilterUDP%`. Если версия не умеет какую-то настройку, она помечается «не используется в vX» и игнорируется.
- **Общая папка** (по умолчанию `<папка версий>\custom`):
  - `bats\` — свои стратегии. Запускаются с файлами выбранной версии.
  - `lists\` — общие списки. Одноимённый файл подменяет список версии, свои списки подключаются как `"%LISTS%my.txt"`.
  - `bin\` — свои фейки.
  - `targets.txt` — цели для проверки.
- **Портативность.** Все настройки, профили, темы и история проверок лежат в `ZapretUE-data` рядом с exe.

## Сборка

```bat
npm install
npm start          :: запуск из исходников
npm test           :: тесты разбора батников, слоёв настроек и списков
npm run dist       :: dist\ZapretUE-<версия>-portable.exe
```

Готовый portable-exe собирает GitHub Actions (`.github/workflows/build.yml`), результат лежит в артефакте **ZapretUE-portable**.

Программа запрашивает права администратора: они нужны winws.exe (WinDivert) и для работы со службой. Вне Windows интерфейс работает в режиме симуляции.
