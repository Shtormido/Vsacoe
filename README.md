# Zapreshatel3000 — управление политиками Windows 10/11

Разработчик: **ЗАО Лига Опасного Интернета**.

Графическая программа для просмотра и изменения групповых политик Windows через реестр.
Работает **во всех редакциях, включая Home**, где нет `gpedit.msc`. Установка не нужна — только встроенный PowerShell 5.1.

## Запуск

1. Скачайте репозиторий: **Code → Download ZIP** и распакуйте.
2. Запустите `Start-Zapreshatel3000.bat` (или ПКМ по `Zapreshatel3000.ps1` → «Выполнить с помощью PowerShell»).
3. Подтвердите запрос UAC — без прав администратора меняются только политики HKCU.

Значок программы берётся из папки `assets` (`icon.ico`, `logo.png`) — держите её рядом с `Zapreshatel3000.ps1`.

## Ограничение пользователей (раздел «Ограничения»)

Для Windows 10/11 **Pro** и выше. Запреты действуют на **всех, кроме администраторов** — через штатную локальную групповую политику «Не администраторы». Учётные записи, созданные позже, тоже попадают под ограничения, а админа запреты не затрагивают.

1. У ограничиваемых людей должны быть **обычные** учётные записи (не администраторы). Программа показывает тип каждой учётки.
   Сменить тип: Параметры → Учётные записи → Другие пользователи → «Изменить тип учётной записи».
2. **Программы** — белый список: запускаются только указанные `.exe` — нажмите «Выбрать из установленных…» и отметьте галочками нужные программы. Всё неотмеченное будет запрещено.
3. **Сайты** — три режима работы белого и чёрного списков:
   - **Чёрный список** — открыто всё, кроме чёрного списка; белый список — исключения, которые открываются всегда.
   - **Белый список** — открыт только белый список, всё остальное запрещено.
   - **Совмещённый** — открыт только белый список, а чёрный дополнительно запрещает разделы внутри разрешённых сайтов (например, разрешить `youtube.com`, но запретить `youtube.com/shorts`).
   Белый список: поисковики, учёба, вход в аккаунты, почта, Госуслуги. Чёрный: соцсети, видео, игры, мессенджеры, кино, ставки, сервисы Яндекса (игры, видео, Дзен, музыка, Кинопоиск — поиск и почта Яндекса остаются).
   Работает в Edge, Chrome, Яндекс, Brave, Vivaldi, Atom, Firefox. Флажок «через hosts» блокирует чёрный список в любом браузере.
4. **Дополнительные запреты**, чтобы ограничения нельзя было обойти: командная строка, редактор реестра, Диспетчер задач, Параметры/Панель управления, режим инкогнито, по желанию — запрет скачивания файлов во всех браузерах на движке Chromium (Edge, Chrome, Яндекс, Brave, Vivaldi, Atom).
5. Нажмите **«Применить ограничения»**. Запреты записываются напрямую в профиль каждого обычного пользователя, а новые учётки получат их через политику «Не администраторы».
6. Выйдите из учётки пользователя и войдите снова — запреты начнут действовать. Кнопка «Проверить, действуют ли ограничения» показывает статус по каждому пользователю.

**Перенос на другой компьютер:** кнопка «Сохранить в файл…» сохраняет программы, сайты и запреты в `.json`. На другом ПК — «Загрузить из файла…» или без интерфейса (PowerShell от администратора):
```powershell
.\Zapreshatel3000.ps1 -ExportRestrictions D:\restrictions.json   # сохранить текущие
.\Zapreshatel3000.ps1 -ImportRestrictions D:\restrictions.json   # применить на этом ПК
```

**Проверка:** войдите под обычной учётной записью, попробуйте запустить программу не из списка (появится окно «Операция отменена из-за ограничений») и открыть заблокированный сайт.

**Ограничения метода:** белый список проверяет программы, запущенные через Проводник (рабочий стол, Пуск, папки). Программу, скачанную и открытую прямо из браузера, он не остановит — для этого включите запрет «скачивания файлов». Запрет скачивания действует только в браузерах на движке Chromium, которые поддерживают политики (Edge, Chrome, Яндекс, Brave, Vivaldi, Atom). В браузерах без поддержки политик (Opera, Firefox, portable-сборки и самодельные браузеры) скачивание так не заблокировать — надёжнее не добавлять их в список разрешённых программ, тогда они просто не запустятся.

**Аварийный откат** (из учётки администратора, cmd от имени администратора):
```
rmdir /s /q C:\Windows\System32\GroupPolicyUsers\S-1-5-32-545
gpupdate /force
```
Посмотреть и вручную изменить эти настройки: Win+R → `mmc` → Файл → Добавить оснастку → «Редактор объектов групповой политики» → Обзор → вкладка «Пользователи» → «Не администраторы».

## Возможности

- **Разделы**: Ограничения · Политики · Реестр · Профили и копии · Инструменты · Журнал (запуски и сайты) · О программе.
- **Журнал запуска приложений**: после включения записи видно, какие программы, когда и под каким пользователем запускались (аудит процессов Windows, событие 4688). Прошлые запуски до включения не сохраняются.
- **Журнал посещённых сайтов**: читает историю браузеров (Chrome, Edge, Яндекс, Brave, Vivaldi, Atom, Opera, Firefox) всех пользователей — реально открытые страницы с полным адресом, временем, пользователем и браузером. Программа **копит записи в собственном журнале** (`data\history_log.tsv`) и пополняет его в фоне, пока открыта, поэтому **очистка истории в браузере не стирает уже сохранённое**. Ничего включать не нужно. Режим инкогнито браузер не записывает (закрывается запретом инкогнито в разделе «Ограничения»).
- **Современный интерфейс** (WPF): боковое меню, карточки, переключатели, цветные статусы, всплывающие уведомления. Разделы: Ограничения · Политики · Реестр · Профили и копии · Инструменты.
- **Ограничения для всех, кроме администраторов**: белый список программ, блокировка сайтов, запрет обхода.
- **Каталог из 65 политик** в 7 категориях: конфиденциальность (телеметрия, Copilot, Recall, реклама), Центр обновления (отключение, отсрочка, фиксация версии), безопасность (UAC, SmartScreen, Defender, USB, автозапуск, PowerShell), сеть (LLMNR, SMB), ограничения пользователя (Диспетчер задач, regedit, cmd, Панель управления), интерфейс (виджеты, OneDrive, Store), Microsoft Edge.
- Текущее состояние каждой политики, поиск, фильтр «Настроенные»; цветом отмечены заданные (зелёный) и нестандартные (оранжевый) значения.
- **Профили** — применение набора политик в один клик: `Конфиденциальность`, `Усиленная безопасность`, `Контроль обновлений`. Текущие настройки можно сохранить как свой профиль.
- **Резервные копии**: создаются автоматически перед первым изменением за сеанс, плюс ручное сохранение и восстановление.
- Вкладка **«Все политики в реестре»**: все параметры из веток Policies (в том числе не из каталога), удаление, переход в regedit, экспорт в `.reg`.
- `gpupdate /force`, HTML-отчёт `gpresult`, запуск `gpedit.msc`, перезапуск Проводника.
- Журнал всех изменений: `data\PolicyManager.log`.

## Командная строка

```powershell
.\Zapreshatel3000.ps1 -List                       # состояние всех политик
.\Zapreshatel3000.ps1 -Backup D:\policies.json    # резервная копия
.\Zapreshatel3000.ps1 -Restore D:\policies.json   # восстановление
.\Zapreshatel3000.ps1 -ApplyProfile privacy       # профиль из папки profiles
```

## Свои политики

Каталог хранится в `policies.json`. Пример записи:

```json
{
  "id": "game_dvr",
  "category": "Интерфейс и система",
  "name": "Запись игр",
  "description": "Отключает фоновую запись игр.",
  "path": "HKLM:\\SOFTWARE\\Policies\\Microsoft\\Windows\\GameDVR",
  "values": [ { "name": "AllowGameDVR", "type": "DWord" } ],
  "options": [ { "key": "off", "label": "Отключить", "data": [0] } ]
}
```

- `values` — параметры реестра (`DWord`, `QWord`, `String`, `ExpandString`); у параметра может быть свой `path`.
- `data` — значения по порядку `values`; `null` — параметр удаляется.
- `noUnset: true` — скрыть вариант «Не задано» (для системных значений вроде UAC); `reboot: true` — нужна перезагрузка.

## Важно

- Программа пишет значения напрямую в реестр (ветки `Policies`), как это делает gpedit. В самом `gpedit.msc` такие изменения **не отображаются**, а если та же политика задана в gpedit или доменной GPO, после `gpupdate` действует она.
- Политики HKCU применяются к пользователю, от имени которого запущена программа. Если UAC запрашивает пароль **другой** учётной записи администратора, HKCU-политики попадут в её профиль.
- Часть политик действует только в Pro/Enterprise/Education — это указано в описании.
- Если после «Запретить выполнение скриптов PowerShell» программа перестала запускаться, выполните в cmd от администратора:
  `reg delete "HKLM\SOFTWARE\Policies\Microsoft\Windows\PowerShell" /f`
