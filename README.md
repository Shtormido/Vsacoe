# Policy Manager — управление политиками Windows 10/11

Графическая программа для просмотра и изменения групповых политик Windows через реестр.
Работает **во всех редакциях, включая Home**, где нет `gpedit.msc`. Установка не нужна — только встроенный PowerShell 5.1.

## Запуск

1. Скачайте репозиторий: **Code → Download ZIP** и распакуйте.
2. Запустите `Start-PolicyManager.bat` (или ПКМ по `PolicyManager.ps1` → «Выполнить с помощью PowerShell»).
3. Подтвердите запрос UAC — без прав администратора меняются только политики HKCU.

## Возможности

- **Каталог из 65 политик** в 7 категориях: конфиденциальность (телеметрия, Copilot, Recall, реклама), Центр обновления (отключение, отсрочка, фиксация версии), безопасность (UAC, SmartScreen, Defender, USB, автозапуск, PowerShell), сеть (LLMNR, SMB), ограничения пользователя (Диспетчер задач, regedit, cmd, Панель управления), интерфейс (виджеты, OneDrive, Store), Microsoft Edge.
- Текущее состояние каждой политики, поиск, фильтр «Настроенные»; цветом отмечены заданные (зелёный) и нестандартные (оранжевый) значения.
- **Профили** — применение набора политик в один клик: `Конфиденциальность`, `Усиленная безопасность`, `Контроль обновлений`. Текущие настройки можно сохранить как свой профиль.
- **Резервные копии**: создаются автоматически перед первым изменением за сеанс, плюс ручное сохранение и восстановление.
- Вкладка **«Все политики в реестре»**: все параметры из веток Policies (в том числе не из каталога), удаление, переход в regedit, экспорт в `.reg`.
- `gpupdate /force`, HTML-отчёт `gpresult`, запуск `gpedit.msc`, перезапуск Проводника.
- Журнал всех изменений: `data\PolicyManager.log`.

## Командная строка

```powershell
.\PolicyManager.ps1 -List                       # состояние всех политик
.\PolicyManager.ps1 -Backup D:\policies.json    # резервная копия
.\PolicyManager.ps1 -Restore D:\policies.json   # восстановление
.\PolicyManager.ps1 -ApplyProfile privacy       # профиль из папки profiles
```

## Свои политики

Каталог хранится в `policies.json`. Пример записи:

```json
{
  "id": "game_dvr",
  "category": "Интерфейс и система",
  "name": "Запись игр",
  "description": "Отключает фоновую запись игр.",
  "path": "HKLM:\\SOFTWARE\\Policies\\Microsoft\\Windows\\GameDVR",
  "values": [ { "name": "AllowGameDVR", "type": "DWord" } ],
  "options": [ { "key": "off", "label": "Отключить", "data": [0] } ]
}
```

- `values` — параметры реестра (`DWord`, `QWord`, `String`, `ExpandString`); у параметра может быть свой `path`.
- `data` — значения по порядку `values`; `null` — параметр удаляется.
- `noUnset: true` — скрыть вариант «Не задано» (для системных значений вроде UAC); `reboot: true` — нужна перезагрузка.

## Важно

- Программа пишет значения напрямую в реестр (ветки `Policies`), как это делает gpedit. В самом `gpedit.msc` такие изменения **не отображаются**, а если та же политика задана в gpedit или доменной GPO, после `gpupdate` действует она.
- Политики HKCU применяются к пользователю, от имени которого запущена программа. Если UAC запрашивает пароль **другой** учётной записи администратора, HKCU-политики попадут в её профиль.
- Часть политик действует только в Pro/Enterprise/Education — это указано в описании.
- Если после «Запретить выполнение скриптов PowerShell» программа перестала запускаться, выполните в cmd от администратора:
  `reg delete "HKLM\SOFTWARE\Policies\Microsoft\Windows\PowerShell" /f`
