# Редактор метаданных (Android)

Приложение для телефона, которое показывает и изменяет метаданные файлов:
**всех форматов Microsoft Office, фотографий и видео**. При первом запуске
открывается пошаговое обучение (его можно открыть снова кнопкой «ⓘ» на главном экране
или из меню редактора).

## Что умеет

| Тип | Форматы | Что можно менять |
|---|---|---|
| Word, Excel, PowerPoint, Visio 2007+ | DOCX, DOCM, DOTX, DOTM, XLSX, XLSM, XLTX, XLTM, XLSB, PPTX, PPTM, PPSX, PPSM, POTX, POTM, VSDX, VSDM | название, тема, автор, кем сохранён, ключевые слова, примечания, категория, состояние, номер редакции, даты создания/изменения/печати, организация, руководитель, программа, шаблон… |
| Office 97-2003 | DOC, DOT, XLS, XLT, PPT, PPS, POT, VSD, PUB, MSG | название, тема, автор, кем сохранён, ключевые слова, примечания, категория, организация, руководитель, даты, программа, шаблон |
| Фото | JPEG, PNG, WebP (HEIC, DNG — просмотр) | описание, комментарий, автор, авторские права, владелец, камера, объектив, серийный номер, программа, даты съёмки, GPS-координаты и высота |
| Видео | MP4, MOV, M4V, 3GP (и аудио M4A) | название, описание, комментарий, жанр, альбом, автор, авторские права, дата, производитель и модель устройства, программа, координаты, даты создания/изменения |

* Кнопка **«Удалить все метаданные»** — стирает личные данные перед отправкой файла.
* **«Сохранить»** перезаписывает исходный файл, **«Копия»** создаёт новый файл.
* Файл можно открыть через **«Поделиться»** / **«Открыть с помощью»** из галереи или файлового менеджера.
* Пустое поле при сохранении удаляет тег из файла.
* Кириллица поддерживается везде (в фото — UTF-8, в старых Office — Unicode-кодировка свойств).
* Содержимое файла (текст, изображение, видеопоток) не изменяется — правятся только блоки свойств.

## Установка

1. Скачайте `app-debug.apk` (во вкладке **Actions** репозитория → последняя сборка → артефакт `proga-metadata-apk`).
2. Откройте файл на телефоне и разрешите установку из неизвестных источников.
3. Требуется Android 8.0 или новее.

## Сборка

```bash
./gradlew :app:assembleDebug        # APK: app/build/outputs/apk/debug/app-debug.apk
./gradlew :app:testDebugUnitTest    # тесты
```

Нужны JDK 17+ и Android SDK (platform 36). Путь к SDK — в `local.properties` (`sdk.dir=...`)
или в переменной `ANDROID_HOME`.

## Устройство проекта

* `core/OoxmlHandler` — `docProps/core.xml` и `docProps/app.xml` внутри ZIP-контейнера Office.
* `core/cfb/CompoundFile`, `core/cfb/PropertySet`, `core/LegacyOfficeHandler` — собственная реализация
  формата OLE2 (MS-CFB) и потоков `SummaryInformation` / `DocumentSummaryInformation` (MS-OLEPS).
* `core/mp4/*` — разбор атомов MP4/QuickTime: `udta/meta/ilst`, ключи Apple `mdta`, `©xyz`, времена в `mvhd/tkhd/mdhd`;
  при изменении размера заголовка смещения `stco/co64` пересчитываются, видеоданные не трогаются.
* `image/*` — EXIF/XMP через AndroidX ExifInterface с поддержкой Unicode, очистка JPEG COM/IPTC и PNG text-чанков.
* `ui/*` — Jetpack Compose: обучение (`OnboardingScreen`), главный экран, редактор.

Тесты проверяют записанные файлы независимой библиотекой Apache POI (Office) и повторным чтением
(видео, фото), а также что данные видео после правки не смещаются.
