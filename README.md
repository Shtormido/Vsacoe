# Живые обои для Windows

Программа для Windows 10/11, которая ставит **анимированные обои на рабочий стол** (позади иконок)
и выводит их **на экран блокировки**.

## Что умеет

**Рабочий стол**
- Видео (`mp4`, `mov`, `wmv`, `avi`, `mkv`, `webm` и т.д.), анимированные GIF и обычные картинки.
- 4 встроенные анимации, файлы для них не нужны: «Северное сияние», «Сеть частиц» (тянется к курсору), «Матрица», «Неоновые волны».
- Работает на всех мониторах. Если менять разрешение или подключать мониторы, обои перестраиваются сами.
- Режимы масштаба: заполнить экран с обрезкой / вписать целиком / растянуть. Звук видео можно включить.
- Экономит ресурсы: ставит обои на паузу во время игр и полноэкранных приложений, по желанию — при развёрнутом окне или от батареи.
  Пока компьютер заблокирован, обои тоже на паузе.
- После перезапуска Explorer обои восстанавливаются сами, а после выхода из программы возвращаются обычные обои Windows.
- Есть автозапуск вместе с Windows.

**Экран блокировки**
- **Живой экран блокировки** — `Ctrl+Alt+L` или пункт меню «Заблокировать с живыми обоями». На весь экран
  идут живые обои с часами и датой. Любая клавиша, щелчок или движение мыши ведут на обычный экран ввода
  пароля Windows, и на нём стоит тот же кадр, так что переход получается плавным.
- **Живая заставка при бездействии** — через 1–30 минут без действий включается то же самое, а потом,
  если включено, компьютер блокируется.
- **Картинка системного экрана блокировки** — при каждой блокировке (в том числе через `Win+L`) туда ставится
  текущий кадр обоев. Можно также обновлять её раз в 5/15/60 минут.
- **Заставка Windows (.scr)** — программу можно зарегистрировать как обычную заставку Windows с запросом
  пароля после неё.

> Почему на экране ввода пароля не идёт видео: Windows рисует этот экран (LockApp) на защищённом рабочем
> столе и не пускает туда окна других программ. Так ограничены все программы живых обоев, в том числе
> Wallpaper Engine и Lively. Поэтому живая анимация показывается **до** экрана с паролем, а на сам экран
> ставится кадр из неё.

## Как запустить

1. Скачайте `JivieOboi.exe`: вкладка **Actions** на GitHub → последняя сборка → артефакт `JivieOboi-win-x64`.
   Можно собрать и самому (см. ниже).
2. Запустите. Рядом с часами появится значок. Всё управление — через меню этого значка (правой кнопкой).
   Двойной щелчок по значку ставит обои на паузу и снимает с неё.

Настройки и журнал ошибок хранятся в `%LocalAppData%\JivieOboi` (`settings.json`, `error.log`).

## Сборка

Нужен [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0).

```bat
build.bat
```

Результат — один файл `publish\JivieOboi.exe`, .NET на компьютере для него не нужен. Для отладки:
`dotnet run --project JivieOboi`. Проект можно открыть и в Visual Studio 2022.

## Как это устроено

| Файл | Что делает |
|---|---|
| `DesktopHost.cs` | Находит окно `WorkerW` позади иконок (сообщение `0x052C` для `Progman`). Поддерживает и новую схему рабочего стола Windows 11 24H2. |
| `DesktopWallpaper.cs` | Встраивает окно WPF (`HwndSource`) в рабочий стол — по одному на монитор. |
| `WallpaperView.cs`, `GifPlayer.cs`, `Scenes/` | Видео (`MediaElement`), GIF, картинки и встроенные анимации. |
| `Lock/LockOverlay.cs`, `Lock/ClockPanel.cs` | Живой экран блокировки с часами. |
| `Lock/LockScreenImage.cs` | Ставит кадр на системный экран блокировки (`Windows.System.UserProfile.LockScreen`). |
| `Lock/WindowsScreensaver.cs` | Регистрирует программу как заставку `.scr`. |
| `TrayApp.cs` | Значок в трее, меню, пауза, горячая клавиша, автозапуск. |

## Ограничения

- Видео играется встроенными кодеками Windows. Надёжнее всего MP4 (H.264). Для HEVC/WebM может понадобиться
  расширение из Microsoft Store.
- Если в организации экран блокировки настроен политикой (или включён «Windows: интересное»), картинку
  на нём программа поменять не сможет. Тогда в «Параметры → Персонализация → Экран блокировки» выберите «Фото».
- Если нужна системная заставка, выключение экрана в настройках питания должно срабатывать позже, чем она.
