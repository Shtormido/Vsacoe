# Нефритовое Го

Игра го в браузере: 3D-стол в семи местах, бот четырёх уровней, обучение, задачи дня, живой звук и спокойная музыка.

```
site/            игра (index.html) и локальные библиотеки и шрифты (vendor/)
server/serve.py  веб-сервер на Python 3, без зависимостей
deploy/          установка сервиса для Kali Linux, пример настройки nginx
```

## Быстрый запуск на Kali Linux

Python 3 в Kali уже есть, больше ничего ставить не нужно.

```bash
git clone -b jade-go https://github.com/Shtormido/Vsacoe.git jade-go
cd jade-go
python3 server/serve.py
```

Сервер покажет адреса, по которым открывать игру:

```
Нефритовое Го: раздаю /home/kali/jade-go/site
  http://localhost:8080/
  http://192.168.1.50:8080/     ← с телефона или другого компьютера в той же сети
```

Другой порт или только локальный доступ: `python3 server/serve.py --port 8000 --host 127.0.0.1`.

## Запуск на Windows 10 и 11

Сервер работает и на Windows: он использует только стандартный Python. Нужен один раз установить Python 3:

- **Python 3** — официальный установщик для Windows: <https://www.python.org/downloads/windows/>. При установке отметьте **Add python.exe to PATH**.
- **Git for Windows**, если хотите скачивать обновления командой `git pull`: <https://git-scm.com/download/win>. Можно и без него: на GitHub нажмите **Code → Download ZIP** (ветка `jade-go`) и распакуйте архив.

Дальше запустите **`start-windows.bat`** двойным щелчком. Откроется окно сервера и браузер с игрой. Пока окно открыто, игра доступна с других устройств по адресам, которые напишет сервер, например `http://192.168.1.50:8080/`.

- Когда Windows спросит про брандмауэр, разрешите доступ для **частных сетей**, иначе телефон и другие компьютеры не подключатся.
- Другой порт: `start-windows.bat 8000`.
- Чтобы сервер запускался вместе с Windows: нажмите Win+R, введите `shell:startup` и положите в открывшуюся папку ярлык на `start-windows.bat`.
- Установщик `deploy/install.sh` нужен только для Linux: на Windows сервис не устанавливается, сервер работает, пока открыто его окно.

## Игра по сети

Когда игра открыта через сервер, в главном меню работает пункт **«Игра по сети»**:

1. Первый игрок вводит имя, выбирает доску, цвет, коми и часы и нажимает «Создать комнату». Он получает код вида `K7P2QX` и ссылку.
2. Второй открывает ссылку (или вводит код в том же окне) — партия начинается сама.

Оба должны видеть сервер: в одной сети достаточно адреса `http://IP-сервера:8080/`; из интернета — проброс порта или туннель (ниже).

Сервер сам проверяет каждый ход и ведёт часы, так что разойтись в позиции или сходить вне очереди нельзя. В партии есть чат, просьба вернуть ход (соперник разрешает или отказывает), совместная отметка мёртвых камней при подсчёте и реванш со сменой цветов. После обновления страницы или обрыва связи партия продолжается с того же места («Продолжить партию» в главном меню).

Комнаты хранятся в памяти сервера: после перезапуска сервиса идущие онлайн-партии пропадают. Неначатые комнаты удаляются через 6 часов, брошенные партии — через сутки.

## Аккаунты

Сервер ведёт аккаунты игроков: регистрация и вход в главном меню («Аккаунт»). Для игры по сети нужен аккаунт, для игры с ботом и вдвоём на одном устройстве — нет.

- Пароли хранятся только как хеш PBKDF2-SHA256 с солью. После входа браузер получает HttpOnly-cookie на 30 дней. После 10 неудачных попыток вход блокируется на 10 минут.
- **Первый зарегистрированный на сервере становится администратором.**
- У каждого игрока рейтинг Эло (начальный 1500), история партий по сети с записью SGF и таблица лучших игроков.
- База — один файл SQLite: `data/jadego.db` рядом с проектом, у сервиса — `/var/lib/jade-go/jadego.db`. Резервная копия — просто копия этого файла.

Режимы регистрации:

| Запуск | Что происходит |
|---|---|
| `python3 server/serve.py` | регистрация открыта для всех |
| `--signup invite` | регистрация только по коду приглашения |
| `--signup closed` | аккаунты создаёт только администратор |
| `--private` | закрытый сервер: без входа открывается только страница входа |

Для сервиса — те же параметры: `sudo ./deploy/install.sh --signup invite --private`.

Управление аккаунтами из командной строки:

```bash
python3 server/accounts.py list                 # все аккаунты, рейтинг, когда заходили
python3 server/accounts.py add LOGIN [--admin]  # создать (пароль спросит)
python3 server/accounts.py passwd LOGIN         # сменить пароль и завершить все входы
python3 server/accounts.py invite --uses 5      # код приглашения на 5 регистраций
python3 server/accounts.py del LOGIN            # удалить
# для установленного сервиса:
sudo -u jadego python3 /opt/jade-go/server/accounts.py --data /var/lib/jade-go list
```

На Windows те же команды: `py server\accounts.py list`.

## Как постоянный сервис

```bash
sudo ./deploy/install.sh              # порт 8080
sudo ./deploy/install.sh --port 80    # обычный веб-порт, адрес без :8080
```

Установщик кладёт игру в `/opt/jade-go` и запускает её от отдельного пользователя `jadego` без прав, с ограничениями systemd. Сервис стартует при загрузке и перезапускается при сбое. Если включён `ufw`, порт откроется сам.

| Действие | Команда |
|---|---|
| Состояние | `systemctl status jade-go` |
| Перезапуск / остановка | `sudo systemctl restart jade-go` / `sudo systemctl stop jade-go` |
| Логи | `journalctl -u jade-go -f` |
| Обновить игру | `git pull && sudo ./deploy/install.sh` |
| Удалить | `sudo ./deploy/install.sh --uninstall` |
| Проверка работы | `curl http://localhost:8080/healthz` → `ok` |

## Через nginx и HTTPS

Если на сервере уже есть nginx или нужен домен с HTTPS, используйте `deploy/nginx-jade-go.conf`. Команды установки написаны в начале файла. Nginx отдаёт файлы игры, а онлайн-партии (`/api/`) передаёт в `serve.py`, поэтому сервис тоже должен работать: `sudo ./deploy/install.sh --host 127.0.0.1`.

- **nginx** — быстрый веб-сервер: `sudo apt install nginx`.
- **Certbot** — бесплатный HTTPS-сертификат Let's Encrypt: <https://certbot.eff.org/>, установка `sudo apt install certbot python3-certbot-nginx`.

## Доступ из интернета

- **Проброс порта на роутере:** внешний порт → IP сервера и порт 8080 (или 80).
- **Без белого IP:**
  - **Cloudflare Tunnel** — бесплатный туннель без открытия портов: <https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/downloads/>, затем `cloudflared tunnel --url http://localhost:8080`.
  - **ngrok** — то же самое, проще для быстрой проверки: <https://ngrok.com/download>, затем `ngrok http 8080`.

## Что умеет сервер

- Раздаёт только папку `site/`: содержимое папок не показывает, скрытые файлы и выход за пределы папки отдаёт как 404.
- Сжимает HTML, JS и CSS (gzip): страница весит 90 КБ вместо 275 КБ.
- Ставит заголовки безопасности (CSP, nosniff, Referrer-Policy) и кэширование: библиотеки кэшируются на 30 дней, сама игра проверяется при каждом заходе, чтобы обновление сразу доходило до игроков.
- Работает без интернета: three.js и шрифты лежат в `site/vendor/`.
- Ведёт онлайн-партии: комнаты на двоих, ходы и часы проверяются на сервере, обновления приходят игрокам мгновенно (Server-Sent Events).

## Если что-то не так

| Сообщение или симптом | Что сделать |
|---|---|
| «порт уже занят» | Найти, кто держит порт: `sudo ss -ltnp \| grep 8080`. Или запустить на другом: `--port 8000`. |
| «Нет прав на порт» | Порты ниже 1024 требуют root: используйте `sudo ./deploy/install.sh --port 80` или порт 8080. |
| С телефона не открывается | Телефон и сервер должны быть в одной сети. Проверьте файрвол: `sudo ufw allow 8080/tcp`. |
| Не работает как сервис | Смотрите `journalctl -u jade-go -n 50`. |

Сохранения, статистика и настройки хранятся в браузере каждого игрока (localStorage), сервер их не собирает.

`site/index.html` можно открыть и без сервера, двойным щелчком: тогда библиотеки загрузятся из интернета.
