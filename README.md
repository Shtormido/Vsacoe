# Дневник

Мобильное приложение-ежедневник (Android и iOS) на Expo / React Native.

## Что умеет

- **День** — цели на день, повседневные задачи (привычки) на этот день, прогресс, листание по дням.
  Невыполненные цели со вчера можно перенести на сегодня одной кнопкой. На любую цель можно поставить
  напоминание ⏰.
- **Неделя** — цели на неделю и обзор всех дней недели (сколько выполнено в каждый день).
- **Братан 🦝** — маскот на экране дня. Хвалит, когда всё сделано, подгоняет вечером, а если вчера
  что-то не выполнено — разочарованно говорит «Брат, я думал ты сможешь...». Нажми на него — скажет другое.
- **Мотивация** — каждый день новая фраза дня, кнопка «Другая фраза» и «Поделиться».
- **Привычки** — повседневные задачи: по каким дням повторять, во сколько напоминать, серия 🔥 дней подряд.
- **Настройки** — напоминания:
  - утром — поставить цели на день (по умолчанию 08:00);
  - вечером — отметить сделанное (21:00);
  - в понедельник — поставить цели на неделю (09:00);
  - «давно не заходил» — если не открывать приложение 2 дня;
  - кнопка тестового уведомления.

Все данные хранятся только на телефоне. Уведомления локальные — интернет и сервер не нужны.

## Скачать APK (Android)

Готовый файл: https://github.com/Shtormido/Vsacoe/releases/latest/download/dnevnik.apk
GitHub Actions пересобирает его при каждом изменении (`.github/workflows/build-apk.yml`).

## Запуск на телефоне (быстро, через Expo Go)

1. Установи **Expo Go** из Google Play / App Store.
2. На компьютере (нужен Node.js 20+):
   ```bash
   npm install
   npx expo start
   ```
3. Отсканируй QR-код из терминала: на Android — в Expo Go, на iPhone — камерой.
4. Разреши уведомления, когда приложение спросит.

Телефон и компьютер должны быть в одной Wi-Fi сети (или запусти `npx expo start --tunnel`).

## Своё приложение (APK для Android)

Чтобы установить дневник как обычное приложение и не зависеть от компьютера:

```bash
npx eas-cli@latest login
npx eas-cli@latest build -p android --profile preview
```

После сборки EAS даст ссылку на `.apk` — открой её на телефоне и установи.
Для iPhone нужна учётная запись Apple Developer (`--profile production`, затем `eas submit`).

## Разработка

```bash
npx tsc --noEmit      # проверка типов
npx expo-doctor       # проверка зависимостей
```

Структура:

- `App.tsx` — вкладки, смена дня, перепланирование уведомлений;
- `src/store.tsx` — состояние и сохранение в AsyncStorage;
- `src/notifications.ts` — разрешения и расписание уведомлений;
- `src/screens/` — экраны, `src/components/` — общие элементы интерфейса.
