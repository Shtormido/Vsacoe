# File Sorter

Программа для Windows: раскладывает файлы выбранной папки по подпапкам по расширению
(`*.exe` → `exe\`, `*.jpg` → `jpg\`, файлы без расширения → `без_расширения\`).

## Возможности
- Выбор папки через «Обзор…».
- Режим поиска:
  - **только в выбранной папке** — вложенные папки не трогаются;
  - **в папке и всех вложенных папках** — файлы из подпапок тоже собираются в папки по типу
    в корне выбранной папки (опционально удаляются опустевшие подпапки).
- Совпадающие имена не перезаписываются: `a.exe` → `a (1).exe`.
- Кнопка «Отменить последнюю сортировку» возвращает файлы на место.
- Журнал перемещений и прогресс-бар.

## Запуск
- **Готовый exe:** вкладка *Actions* репозитория → последний запуск *Build Windows exe* → артефакт `FileSorter`.
- **Из исходника:** установить [Python 3](https://www.python.org/downloads/windows/) (галочка «Add to PATH»),
  затем `python file_sorter.py`.
- **Собрать exe самому:** запустить `build.bat` → `dist\FileSorter.exe`.
