# Живые обои 2.0 для Windows 11

Бесплатная замена Wallpaper Engine. Ставит живые обои на рабочий стол (позади иконок) и на экран
блокировки — на **все подключённые мониторы**. Сделано для **Windows 11**, работает и на Windows 10.

## Возможности

### Обои
- **Видео**: MP4, WebM, MKV, MOV, AVI и другие. Играет движок Chromium (WebView2) с аппаратным ускорением
  и без рывков на повторе.
- **Веб-обои**: HTML/JS/WebGL-страницы из папки или **любой сайт по ссылке** (например, шейдеры с Shadertoy).
- **GIF и картинки**.
- **5 встроенных анимаций**: «Северное сияние», «Сеть частиц», «Эквалайзер», «Матрица», «Неоновые волны».
  У каждой настраиваются скорость и оттенок.
- **Реакция на музыку**: программа слышит, что играет на компьютере (захват системного звука WASAPI,
  микрофон не используется). Эквалайзер пляшет, анимации пульсируют в такт.
- **Интерактивные обои**: движения и щелчки мыши по пустому рабочему столу передаются веб-обоям.

### Совместимость с Wallpaper Engine
- **Импорт в один клик.** Программа сама находит обои, скачанные в Wallpaper Engine (мастерская Steam,
  во всех библиотеках Steam). Добавляются обои типов «видео» и «веб».
- **JS-API Wallpaper Engine:** `wallpaperPropertyListener` (`applyUserProperties`, `applyGeneralProperties`,
  `setPaused`) и `wallpaperRegisterAudioListener` — 128 значений спектра, как в оригинале. Поэтому веб-обои из
  мастерской, в том числе аудиовизуализаторы, работают без переделок.
- **Настройки обоев** из `project.json` (цвета, ползунки, флажки, списки, текст) появляются в программе
  и применяются на лету.
- Обои типов «сцена» и «приложение» работают только внутри самого Wallpaper Engine, их перенести нельзя.

### Мониторы
- **Одни обои на всех мониторах**, **разные на каждом** или **одни, растянутые на все**.
- Если подключить или отключить монитор, обои перестроятся сами.

### Экран блокировки — на всех мониторах
- **Живой экран блокировки** (`Ctrl+Alt+L`): на каждом мониторе свои обои и часы — на всех мониторах или
  только на основном. Если подключить монитор, пока экран блокировки показан, он появится и там.
  От любого нажатия программа переходит к экрану ввода пароля.
- Можно выбрать **отдельные обои для экрана блокировки**.
- **Живая заставка при бездействии** (1–30 минут) с блокировкой после неё.
- На **экран ввода пароля** ставится кадр из обоев, в том числе при `Win+L`.
- Программу можно сделать **заставкой Windows** (`.scr`).

> Экран ввода пароля Windows рисуется на защищённом рабочем столе, куда сторонние программы не допускаются,
> и он показывает одну картинку на всех мониторах. Так ограничены все программы, включая Wallpaper Engine
> и Lively. Поэтому живая анимация на всех мониторах идёт **до** ввода пароля, а на экран с паролем ставится кадр.

### Плейлисты
- Обои меняются автоматически: раз в 5 минут, раз в сутки или с другим интервалом, по порядку или случайно.

### Производительность
- **Пауза** в играх и полноэкранных приложениях, в выбранных программах, при развёрнутом окне или от батареи.
- Если экран не виден, веб-обои полностью замораживаются и не тратят процессор и видеокарту.
- **Режим эффективности Windows 11** (зелёный листик в диспетчере задач) на время паузы.
- Ограничение кадров в секунду: 24, 30, 60 или 120.

### Сделано под Windows 11
- Окно программы в стиле Windows 11 (тема Fluent): светлая или тёмная тема — как в системе.
- Меню в трее со скруглёнными углами и акцентным цветом.
- Поддерживается новый рабочий стол Windows 11 24H2 и новее.
- Есть сборка для ARM-ноутбуков (Snapdragon).

## Как пользоваться

1. Скачайте `JivieOboi.exe` во вкладке **Actions** на GitHub: последняя сборка → `JivieOboi-win-x64`
   (для ARM — `JivieOboi-win-arm64`). У программы нет цифровой подписи. Если Windows скажет
   «Windows защитила ваш компьютер», нажмите «Подробнее» → «Выполнить в любом случае».
2. Запустите. Откроется **библиотека**. Двойной щелчок по обоям — поставить. Справа — их настройки.
3. Чтобы добавить свои обои, нажмите **«+ Файл»** или просто перетащите видео, GIF, картинку или папку
   с веб-обоями в окно. Для обоев из Wallpaper Engine есть кнопка **«Импорт из Wallpaper Engine»**.
4. Поле **«Куда ставить»** выбирает, на какой монитор ставить обои (или на все).
5. Если закрыть окно, обои продолжат работать. Значок в трее снова открывает библиотеку.

Настройки, библиотека, превью и журнал ошибок лежат в `%LocalAppData%\JivieOboi`.

## Свои веб-обои

Подойдёт любая папка с `index.html`. Чтобы обои были совместимы с Wallpaper Engine, положите рядом
`project.json`:

```json
{
  "title": "Мои обои",
  "type": "web",
  "file": "index.html",
  "preview": "preview.jpg",
  "general": {
    "properties": {
      "color": { "type": "color", "text": "Цвет", "value": "0.2 0.6 1" },
      "speed": { "type": "slider", "text": "Скорость", "min": 1, "max": 100, "value": 50 }
    }
  }
}
```

```js
window.wallpaperPropertyListener = {
  applyUserProperties(p) { if (p.color) setColor(p.color.value); if (p.speed) setSpeed(p.speed.value); }
};
window.wallpaperRegisterAudioListener(spectrum => draw(spectrum)); // 128 чисел: 64 левый + 64 правый канал
```

## Сборка

Нужен [.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0).

```bat
build.bat          :: обычные ПК — publish\win-x64\JivieOboi.exe
build.bat arm64    :: ARM — publish\win-arm64\JivieOboi.exe
```

Получится один exe-файл, .NET для него ставить не нужно. WebView2 Runtime уже есть в Windows 11.

## Как это устроено

| Папка | Что внутри |
|---|---|
| `Core/` | Настройки, библиотека, импорт из Wallpaper Engine, превью, захват звука и спектр, Win32 API |
| `Render/` | Движки обоев: WebView2 (веб и видео) с JS-API Wallpaper Engine, видео через Media Foundation, GIF, встроенные анимации |
| `Desktop/` | Встраивание в рабочий стол (WorkerW/Progman, в том числе схема 24H2), обои по мониторам, плейлист, мышь для интерактивных обоев |
| `Lock/` | Живой экран блокировки на всех мониторах, часы, кадр на экран ввода пароля, заставка `.scr` |
| `UI/` | Окно-библиотека (Fluent), меню в трее, контроллер приложения |

## Ограничения

- Обои Wallpaper Engine типов «сцена» и «приложение» не поддерживаются.
- Если экран блокировки настроен политикой организации или включено «Windows: интересное», картинку
  на экране ввода пароля программа поменять не сможет. В «Параметры → Персонализация → Экран блокировки»
  выберите «Фото».
