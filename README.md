# MP3UP — твоя музыка

Музыкальный плеер для своей коллекции MP3 — в духе Spotify и Яндекс Музыки, но без подписок, рекламы и интернета. Все треки хранятся только в браузере на вашем устройстве.

## Запуск

Сборка не нужна — это обычные HTML, CSS и JS.

- **Просто послушать:** откройте `index.html` в браузере.
- **Установить как приложение:** MP3UP нужно открыть через сайт или локальный сервер (с диска браузер установку не разрешает):
  - **GitHub Pages** — в репозитории: *Settings → Pages → Build and deployment → Source: Deploy from a branch*, ветка `plyer_mp3up`, папка `/ (root)` → *Save*. Через минуту плеер будет по адресу `https://shtormido.github.io/Vsacoe/`.
  - **Без интернета-хостинга** — запустите `start.bat` (Windows) или `start.sh` (macOS, Linux). Нужен Python 3. Откроется `http://localhost:8737`.

## Установка как приложение

Откройте MP3UP по ссылке и нажмите **«Установить»** вверху страницы.

- **Windows, macOS, Linux (Chrome, Edge, Яндекс Браузер)** — появится окно установки. MP3UP откроется в своём окне, получит значок на рабочем столе и в меню «Пуск», а MP3‑файлы можно будет открывать через *«Открыть с помощью → MP3UP»*.
- **Android** — «Установить» или меню ⋮ → «Установить приложение».
- **iPhone / iPad** — Safari → «Поделиться» → «На экран „Домой“».

Установленное приложение работает без интернета. У значка есть быстрые действия: «Моя волна», «Медиатека», «Любимые треки».

## Android‑приложение (APK)

**Скачать:** https://github.com/Shtormido/Vsacoe/releases/latest/download/MP3UP.apk

Откройте файл на телефоне и разрешите установку из этого источника, если Android спросит. Нужен Android 7 или новее.

В APK весь плеер встроен внутрь — интернет не нужен. Дополнительно к веб‑версии:
- музыка играет в фоне и при выключенном экране;
- уведомление с обложкой и кнопками ⏮ ⏯ ⏭, управление с экрана блокировки, наушников и Bluetooth;
- «Открыть с помощью MP3UP» и «Поделиться → MP3UP» для аудиофайлов из проводника, Telegram и т. п.;
- кнопка «Назад» закрывает окна и плеер, а не приложение.

Каждый push в ветку `plyer_mp3up` автоматически собирает новый APK (GitHub Actions → Releases). Новые версии ставятся поверх старых, медиатека сохраняется.

Собрать вручную (нужны JDK 17+ и Android SDK):
```bash
cd android
./gradlew assembleRelease
# готовый файл: android/app/build/outputs/apk/release/app-release.apk
```

> Ключ подписи `android/app/mp3up-release.jks` лежит в репозитории, чтобы обновления из любой сборки ставились поверх. Перед публикацией в Google Play замените его своим.

## Что умеет

- **Добавление музыки** — кнопкой, целыми папками или перетаскиванием файлов в окно. MP3, M4A, FLAC, OGG, WAV.
- **Теги и обложки** — название, исполнитель, альбом, жанр и обложка читаются из ID3 (v1, v2.2–2.4). Правильно понимает русские теги в кодировке Windows‑1251. Если тегов нет, название берётся из имени файла `Исполнитель - Трек.mp3`.
- **Главная** — приветствие, быстрые плитки, недавно добавленное, часто слушаемое, альбомы и исполнители.
- **«Моя волна»** — бесконечный поток из вашей медиатеки: любимые и часто слушаемые треки звучат чаще, недавние — реже.
- **Медиатека** — треки (с сортировкой), альбомы, исполнители, плейлисты.
- **Любимые треки и плейлисты** — ♥ одним нажатием, создание, переименование, удаление, добавление треков через удобный поиск.
- **Мгновенный поиск** по трекам, исполнителям, альбомам и жанрам.
- **Плеер** — перемешивание, повтор (всё / один трек), очередь («играть следующим», «добавить в очередь»), громкость, перемотка.
- **Полноэкранный режим** — большая обложка, фон под цвет обложки и визуализатор звука.
- **Онлайн‑музыка** — раздел «Онлайн» с тремя бесплатными и легальными источниками, без подписок и рекламы:
  - **Audius** — чарты недели по жанрам и поиск по миллионам треков, которые артисты сами выкладывают для бесплатного прослушивания;
  - **Jamendo** — независимые артисты под Creative Commons. Нужен личный бесплатный Client ID (devportal.jamendo.com), его вставляют прямо в разделе «Онлайн». Эквалайзер и визуализатор для этих треков не работают — сервер Jamendo не разрешает обработку звука;
  - **Internet Archive** — альбомы нетлейблов под Creative Commons, записи живых концертов и оцифрованные пластинки 78 об/мин.

  ♥ или «Сохранить в медиатеку» добавляет онлайн‑трек в медиатеку и плейлисты (играет при наличии интернета).
- **Эквалайзер** на 5 полос с пресетами («Больше баса», «Вокал», «Рок» и др.).
- **Продолжение с того же места** после перезапуска, кнопки на наушниках и экране блокировки (Media Session).
- **Тёмная и светлая тема**, адаптив под телефон (нижнее меню, мини‑плеер, свайп вниз закрывает плеер).

## Горячие клавиши

| Клавиша | Действие |
|---|---|
| Пробел | Слушать / пауза |
| Shift + → / ← | Следующий / предыдущий трек |
| → / ← | Перемотка на 5 секунд |
| ↑ / ↓ | Громкость |
| M | Без звука |
| L | В «Любимые» |
| S / R | Перемешать / режим повтора |
| F | Полноэкранный плеер |
| Q | Очередь |
| E | Эквалайзер |
| / | Поиск |
| Esc | Закрыть окно |

## Структура

```
index.html            разметка и иконки
css/style.css         оформление (темы, адаптив)
js/db.js              хранилище IndexedDB
js/tags.js            чтение ID3‑тегов и обложек
js/app.js             логика: медиатека, плеер, экраны
sw.js                 офлайн‑режим
manifest.webmanifest  установка как приложение
icons/                значки приложения
start.bat, start.sh   запуск на локальном сервере
android/              Android‑приложение (обёртка с фоновым воспроизведением)
```
