# Придорожный Мотель

2D пиксель-арт хоррор-кулинарный симулятор для браузера (вид сверху, в духе Stardew Valley).

Днём — повар закусочной при мотеле (08:00–00:00), ночью — тихая ночная заготовка особого ресурса,
утром — приведение бумаг в порядок, закупки, ремонт, подкуп и управление персоналом.

## Запуск

Чистые HTML/CSS/JS без сборки. Откройте `index.html` или раздайте папку любым статическим сервером:

```
python3 -m http.server 8000
```

## Управление

- **WASD / стрелки** — ходьба
- **E / Enter** — действие
- **Пробел** — удар в ночной мини-игре
- **Esc** — закрыть окно
- На телефоне — экранные кнопки

## Системы

- Кухня: бургеры, шаурма, фирменное блюдо, наггетсы, картошка, напитки; выбор мяса (обычное / животных / особое) — и кому его подать
- Клиенты: проезжие, постоянные, по рекомендации, богачи; внимательность, подозрения от вкуса, слухи
- Сон 00:00–02:00 влияет на выносливость (скорость, дрожь рук, ошибки)
- Ночь: выбор постояльца (возраст, телосложение, подозрительность, ценность, секреты), стелс мимо неспящих и фар патруля, мини-игра тайминга
- Утро: подделка журнала, вещи, машины, следы; чистота мотеля и подозрения города; режим «торопиться»
- Персонал: повар-помощник, подставной постоялец, смотритель, уборщица, человек «на вывоз» — лояльность, подозрительность, шантаж, предательство
- Прогрессия: оборудование, рецепты, звукоизоляция, камеры, тайные ходы; репутация ресторана и мотеля
- События: санэпидемстанция, шериф, клиент, который слишком много знает; галлюцинации при низкой совести
- 5 концовок: легенда, тюрьма, продать всё и скрыться, закрыть мотель по совести, гибель

Прогресс сохраняется в браузере каждое утро.
