# Zapreshatel3000 — полная инструкция

Версия 2.2. Программа ограничивает запуск программ и доступ к сайтам для всех пользователей ПК, кроме администратора, и умеет рассылать настройки на другие компьютеры в локальной сети.

Всё работает на PowerShell — отдельного `.exe` нет. Запуск от имени администратора обязателен.

---

## 1. Что в архиве

**Главный комплект (`Zapreshatel3000_v2.2.zip`)** — ставится на главный (управляющий) ПК:

| Файл | Назначение |
|---|---|
| `Start-Zapreshatel3000.bat` | Запуск главного приложения (двойной клик) |
| `Zapreshatel3000.ps1` | Само приложение |
| `policies.json` | Каталог политик Windows |
| `profiles/` | Готовые наборы настроек |
| `assets/` | Иконка и логотип |
| `Zapreshatel3000-Agent.ps1`, `Start-Agent.bat`, `agent-config.json` | Файлы клиента (если этот ПК тоже должен быть под контролем) |

**Клиентский комплект (`Zapreshatel3000-Client_v2.2.zip`)** — копируется на каждый подконтрольный ПК:

| Файл | Назначение |
|---|---|
| `Start-Agent.bat` | Запуск клиента-агента |
| `Zapreshatel3000-Agent.ps1` | Агент: связь с сервером и применение |
| `agent-config.json` | Адрес сервера, порт, пароль |
| `Zapreshatel3000.ps1`, `policies.json` | Нужны агенту, чтобы применять ограничения |

---

## 2. Первый запуск главного приложения

1. Распакуйте главный архив в постоянную папку (например, `C:\Zapreshatel3000`). Не запускайте прямо из архива.
2. Двойной клик по `Start-Zapreshatel3000.bat`.
3. Согласитесь на запрос прав администратора (UAC). Без админа программа ничего не ограничит.
4. Откроется окно с разделами слева.

> Настройки и журналы хранятся в `%LOCALAPPDATA%\Zapreshatel3000` и сохраняются между запусками и при обновлении программы.

## 3. Ограничения на локальном ПК (вкладка «Ограничения»)

### Программы (белый список)
- Включите «Разрешить только выбранные программы».
- Отметьте нужные программы из списка установленных или добавьте вручную.
- Обязательно оставьте `explorer.exe`, иначе у пользователей не будут открываться папки.

### Сайты — три режима
- **Чёрный список** — открыто всё, кроме указанного. Белый список здесь работает как исключения.
- **Белый список** — открыт только белый список, остальное закрыто.
- **Совмещённый** — открыт только белый список, а чёрный дополнительно запрещает разделы внутри него.

Форматы адресов:
- домен: `youtube.com` (покрывает и поддомены: `m.youtube.com`);
- раздел сайта: `yandex.ru/games`;
- конкретный IP локальной сети: `192.168.1.113` или с портом `192.168.1.113:8080`.
- Диапазоны/подсети (`192.168.0.0/16`) **не поддерживаются** — вписывайте адреса по одному.

Кнопки-пресеты быстро добавляют наборы (соцсети, видео, игры, сервисы Яндекса и Google).

Галочка «через hosts» дублирует чёрный список через системный файл hosts — работает в любом браузере, но затрагивает и администратора.

### Дополнительные запреты
Командная строка, редактор реестра, Диспетчер задач, Параметры, режим инкогнито, запрет скачивания файлов — чтобы ограничения нельзя было обойти.

### Применение
Нажмите **«Применить ограничения»**. Ограничения действуют для всех пользователей **без прав администратора**. Чтобы проверить — выйдите из учётной записи пользователя и зайдите снова (или перезапустите браузер).

Кнопка **«Снять все»** убирает все ограничения со всех пользователей.

## 4. Удалённое управление по локальной сети

Схема: **главное приложение = сервер**, на других ПК работают **клиенты (агенты)**. Клиенты сами подключаются к серверу (только исходящие соединения), сообщают статус и автоматически применяют присланные ограничения.

### Шаг 1. Запуск сервера на главном ПК
1. Откройте вкладку **«Удалённые ПК»**.
2. Задайте **порт** (по умолчанию `8777`) и **пароль** (латиница и цифры, без пробелов).
3. Нажмите **«Запустить сервер»**.
4. Если Windows спросит про брандмауэр — разрешите доступ (частные сети).
5. Запомните **IP этого компьютера** — он показан тут же, под кнопкой.

### Шаг 2. Настройка клиента на каждом ПК
1. Распакуйте клиентский архив в постоянную папку.
2. Откройте `agent-config.json` блокнотом и впишите:
   ```json
   {
     "server": "192.168.1.10",   // IP главного ПК из шага 1
     "port": 8777,                // тот же порт
     "password": "ваш-пароль",    // тот же пароль
     "interval": 30                // как часто связываться, секунд
   }
   ```
3. Запустите `Start-Agent.bat` и согласитесь на права администратора.
4. В окне агента появятся сообщения о связи с сервером. Компьютер появится в списке на сервере.

### Шаг 3. Рассылка ограничений
1. На главном ПК настройте нужные ограничения на вкладке **«Ограничения»**.
2. Перейдите на вкладку **«Удалённые ПК»** → **«Разослать текущие ограничения»**.
3. Клиенты применят их автоматически при следующей связи (в пределах `interval`).

### Список «Подключённые компьютеры»
Показывает по каждому ПК: имя, пользователя, IP, версию, статус (онлайн/офлайн), применены ли последние настройки, время последней связи.

### Исключения для отдельного ПК
Выберите ПК в списке и ниже:
- **Дополнительно разрешить / заблокировать** — добавляет адреса поверх общих настроек только для этого ПК.
- **Полностью снять ограничения для этого ПК** — этот компьютер останется без ограничений.
- **«Сохранить исключения»** — применится при следующей связи. **«Очистить»** — вернуть общие настройки.

## 5. Автозапуск клиента (по желанию)

Чтобы агент стартовал при включении ПК, создайте задачу в Планировщике заданий:
1. Планировщик заданий → «Создать задачу».
2. Вкладка «Общие»: «Выполнять с наивысшими правами», «Выполнять для всех пользователей».
3. Триггер: «При запуске компьютера».
4. Действие: программа `powershell.exe`, аргументы:
   `-NoProfile -ExecutionPolicy Bypass -File "C:\путь\Zapreshatel3000-Agent.ps1"`
5. Сохранить.

(Могу сделать кнопку автозапуска в самой программе — скажите.)

## 6. Если что-то не работает

**Сервер не запускается / «порт занят»** — смените порт (например, 8778) и в сервере, и в `agent-config.json` на всех клиентах.

**Клиент пишет «нет связи с сервером»:**
- проверьте, что сервер запущен;
- `server` в `agent-config.json` = реальный IP главного ПК;
- порт и пароль совпадают;
- на главном ПК в брандмауэре разрешён этот порт (частная сеть);
- оба ПК в одной локальной сети (пинг `ping IP-главного-ПК` проходит).

**Настройки не применяются на клиенте** — агент должен быть запущен от администратора (`Start-Agent.bat` запрашивает это сам). Проверьте окно агента на ошибки.

**Белый список блокирует даже разрешённые сайты** — сделайте «Снять все», заново настройте и **полностью** перезапустите браузер на аккаунте пользователя (или перезагрузите ПК): браузер держит старые политики до перезапуска.

**Диагностика** — вкладка «Инструменты» → «Журнал изменений» (там видно, какие фильтры ушли в браузер: строки `URLAllowlist` / `URLBlocklist`).

## 7. Требования
- Windows 10 или 11 (включая Home).
- PowerShell 5.1 (есть в системе по умолчанию).
- Права администратора на каждом ПК, где применяются ограничения.
