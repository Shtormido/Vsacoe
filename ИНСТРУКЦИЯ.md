# Zapreshatel3000 — полная инструкция

Программа ограничивает запуск программ и доступ к сайтам для всех пользователей ПК, кроме администратора, управляет политиками Windows 10/11 (включая Home) и умеет переносить все настройки на другое устройство одним файлом.

Работает на PowerShell. Запуск от имени администратора обязателен.

---

## 1. Что в архиве

| Файл | Назначение |
|---|---|
| `Start-Zapreshatel3000.bat` | Запуск программы (двойной клик) |
| `Zapreshatel3000.ps1` | Само приложение |
| `policies.json` | Каталог политик Windows |
| `profiles/` | Готовые наборы настроек |
| `assets/` | Иконка и логотип |
| `ИНСТРУКЦИЯ`, `МАНУАЛ` | Документация |

---

## 2. Первый запуск

1. Распакуйте архив в постоянную папку (например, `C:\Zapreshatel3000`). Не запускайте прямо из архива.
2. Двойной клик по `Start-Zapreshatel3000.bat`.
3. Согласитесь на запрос прав администратора (UAC). Без админа программа ничего не ограничит.

> Настройки и журналы хранятся в `%LOCALAPPDATA%\Zapreshatel3000` и сохраняются между запусками и при обновлении программы.

---

## 3. Ограничения (вкладка «Ограничения»)

Ограничения действуют на всех пользователей ПК, **кроме администратора**. Поэтому ограничиваемая учётка должна быть **обычной** (не админом), а проверять надо под ней.

### Программы (белый список)
- Включите «Разрешить только выбранные программы».
- Отметьте нужные или добавьте вручную. Обязательно оставьте `explorer.exe`.

### Сайты — три режима
- **Чёрный список** — открыто всё, кроме указанного (белый список = исключения).
- **Белый список** — открыт только белый список, остальное закрыто.
- **Совмещённый** — открыт только белый список, чёрный режет разделы внутри него.

Форматы адресов: домен `youtube.com` (покрывает поддомены), раздел `yandex.ru/games`, локальный IP `192.168.1.113` (можно с портом). Диапазоны/подсети не поддерживаются.

Кнопки-пресеты быстро добавляют наборы. Галочка «через hosts» дублирует чёрный список в любом браузере (затрагивает и администратора).

### Дополнительные запреты
Командная строка, редактор реестра, Диспетчер задач, Параметры, режим инкогнито, запрет скачивания — чтобы ограничения нельзя было обойти.

### Применение
Нажмите **«Применить ограничения»**. Проверка — под обычным пользователем (перезайти или полностью перезапустить браузер). Кнопка **«Снять все»** убирает все ограничения.

## 4. Перенос настроек на другое устройство (вкладка «Конфигурация»)

Вся настройка (программы, списки сайтов и режим, дополнительные запреты) сохраняется в один файл и переносится на другой ПК — вводить заново не нужно.

1. Настройте всё как нужно на вкладке «Ограничения».
2. Вкладка **«Конфигурация»** → **«Сохранить конфигурацию в файл…»** → получите `.json`. На этой же вкладке видно текущую конфигурацию.
3. Перенесите файл на другой компьютер (флешка, сеть, почта).
4. На другом ПК: откройте программу → вкладка **«Конфигурация»** → **«Загрузить конфигурацию из файла…»** → подтвердите применение (или проверьте на вкладке «Ограничения» и нажмите «Применить»).

> То же доступно кнопками «Сохранить в файл…» / «Загрузить из файла…» на вкладке «Ограничения».

---

## 5. Прочие вкладки
- **Политики Windows** — конфиденциальность, обновления, безопасность, интерфейс, Edge.
- **Реестр** — все параметры из веток Policies, удаление, экспорт в `.reg`.
- **Профили и копии** — готовые наборы, резервные копии.
- **Инструменты** — `gpupdate`, отчёт `gpresult`, `gpedit.msc`, журнал изменений, удаление программы.
- **Журнал** — запуск программ и посещённые сайты на этом ПК.

---

## 6. Если что-то не работает

| Проблема | Решение |
|---|---|
| «Всё осталось доступно» | Проверяете под администратором — на него запреты не действуют. Проверяйте под обычным пользователем |
| Ограничиваемый — админ | Сделайте его обычным: Параметры → Учётные записи → Изменить тип записи → «Обычный пользователь» |
| Сайты не закрылись | Полностью перезапустите браузер (или перезагрузите ПК) под пользователем |
| Белый список закрыл всё | «Снять все», настроить заново, перезапустить браузер |
| Программа ничего не меняет | Запускайте от администратора |

Диагностика: «Инструменты» → «Журнал изменений» (строки `URLAllowlist` / `URLBlocklist`).

---

## 7. Требования
- Windows 10 или 11 (включая Home).
- PowerShell 5.1 (есть в системе по умолчанию).
- Права администратора.
